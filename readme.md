# 产品定位：

## 跨工业软件的插件
1. 为什么是插件：因为工业软件跟IDE不同，非常重而且有很强的使用壁垒
2. 为什么要跨软件：因为单一软件的功能很容易被吸收掉，跨软件跨流程，把软件作为人与AI的交互方式是更好的定位

## 针对的客群是专业用户（B端）
1. 创客虽然更广泛也明确会增长，但可能GPT就可以，而且付费不稳定
2. 专业工程师的粘性更久，但往往数据安全是一个问题，需要用2B的模式来服务。类似cursor对应词元的差异，但在程序员的领域，前者应该是后者的百倍市值，在工程师领域，我认为专业工程师市场应该是创客的10倍以上

## 要从刚需做起，所以先做3D转2D
1. 只做Copilot（工业的设计工作比较复杂，初期Agent很难端到端完成任务），很难计算ROI，难以说服B端客户
2. 从更窄的刚需来做好效果，会是更好的切入方式，后续可以提供更加丰富的功能来引入真正的通用Agent

## 渐进式的功能
1. 基础问答（类似一些标准），设计审核，图纸生成，自动化（宏定义和管理）
2. 数据集成，本地数据、零部件数据集，做检索和匹配
3. 真正的生成：预测下一步操作（part文件里面能否提取完整的操作过程？），生成某个零部件
