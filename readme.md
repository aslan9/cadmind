# 产品定位

## 跨工业软件的插件
1. 为什么是插件：因为工业软件跟 IDE 不同，非常重而且有很强的使用壁垒。
2. 为什么要跨软件：因为单一软件功能容易被吸收；跨软件、跨流程，把软件作为人与 AI 的交互方式是更好的定位。

## 针对客群：专业用户（B 端）
1. 创客虽然更广泛且会增长，但可能通用 GPT 即可满足，且付费稳定性较弱。
2. 专业工程师粘性更高，但数据安全是关键问题，需要 2B 模式服务。

## 切入策略：从刚需做起，先做 3D 转 2D
1. 只做 Copilot（工业设计工作复杂，初期 Agent 很难端到端完成任务）ROI 难量化，难以说服 B 端客户。
2. 从更窄的刚需做出效果，是更好的切入方式；后续再扩展通用 Agent 能力。

## 渐进式功能方向
1. 基础问答（标准规范）、设计审核、图纸生成、自动化（宏定义和管理）。
2. 数据集成：本地数据、零部件数据集，做检索和匹配。
3. 真正生成：预测下一步操作、生成某个零部件。
